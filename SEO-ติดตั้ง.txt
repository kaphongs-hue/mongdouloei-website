ชุดปรับ SEO หน้าแรก — มองดูเลยโฮมสเตย์

ไฟล์ที่ต้องอัปโหลดไปยังโฟลเดอร์หลักใน GitHub:
1. index.html — แทนไฟล์เดิม (เก็บระบบแคปชั่น 30 ชุดสลับรายวันไว้แล้ว)
2. robots.txt — เพิ่มใหม่ หากบน GitHub มีไฟล์นี้อยู่แล้ว ให้ตรวจและรวมกฎเดิมก่อนแทน
3. sitemap.xml — เพิ่มใหม่ หากมีแผนผังเดิมอยู่แล้ว ให้รวมรายการหน้าสาธารณะเดิม

สำรองไฟล์เดิมก่อนแทน ไม่ต้องลบไฟล์ภาพ booking.html หรือไฟล์อื่นของเว็บไซต์
ไม่ต้องอัปโหลดเอกสารคำแนะนำนี้
การแก้ไขนี้ยังไม่ได้เผยแพร่ไปยังเว็บไซต์จริง

สิ่งที่แก้:
- ชื่อหน้าและคำอธิบายเกี่ยวกับที่พักไฮตาก ภูเรือ จังหวัดเลย
- canonical, ข้อมูลแชร์ และข้อมูลที่พัก ใช้โดเมนมองดูเลย.com
- canonical หน้าแรกใช้ https://xn--72c0azbgo9b4eqc.com/ ทั้งเมื่อเปิด / และ /index.html
- แก้เบอร์โทรและที่อยู่ตัวอย่างเป็นข้อมูลที่แสดงบนเว็บไซต์ที่ตรวจไว้
- เพิ่ม WebSite structured data และปรับ LodgingBusiness โดยไม่แต่งคะแนนรีวิว
- แสดงที่อยู่และเบอร์โทรได้แม้ข้อมูลจาก Firebase ยังไม่โหลด
- เนื้อหาหลักไม่ถูกซ่อนหากโมดูลภายนอกโหลดไม่สำเร็จ
- แผนผังเว็บไซต์มีหน้าแรกและหน้าจอง ไม่ใส่หน้าผู้ดูแลหรือหน้าที่มีข้อมูลการจองส่วนตัว
- ไม่แก้ระบบจอง โปรโมชั่น รูปภาพ หรือชุดแคปชั่นรายวัน

หลังอัปโหลดและเว็บไซต์เผยแพร่สำเร็จ:
1. ตรวจหน้าแรก หน้าจอง เบอร์โทร และรูปภาพอีกครั้ง
2. เปิด https://xn--72c0azbgo9b4eqc.com/robots.txt และ /sitemap.xml ให้โหลดได้
3. ใน Google Search Console ยืนยันความเป็นเจ้าของโดเมนมองดูเลย.com หากยังไม่เคยทำ
4. ส่ง sitemap.xml และใช้ URL Inspection ตรวจหน้าแรก/ขอจัดทำดัชนี
5. ใช้ Google Rich Results Test ตรวจข้อมูลบน URL ที่เผยแพร่แล้ว
6. ตรวจข้อมูลที่อยู่และเบอร์โทรใน Google Business Profile ให้ตรงกับเว็บไซต์

ขอบเขต: ปรับหน้าแรกและไฟล์ช่วยการค้นพบหน้าเท่านั้น ไม่ใช่การตรวจครบทุกหน้า
ยังไม่ได้ตรวจสิทธิ์ Search Console, สถานะการจัดทำดัชนี, Core Web Vitals,
การยืนยัน Google Business Profile หรือการตั้งค่า redirect ของเซิร์ฟเวอร์
robots.txt ไม่ใช่ระบบป้องกันข้อมูลส่วนตัว หน้าแอดมินต้องมีการตรวจสิทธิ์จริง
Google เป็นผู้ตัดสินใจว่าจะจัดทำดัชนี แสดงชื่อ/คำอธิบาย หรือจัดอันดับอย่างไร
การสลับแคปชั่นรายวันไม่ใช่การรับประกันอันดับ และไม่มีการรับประกันอันดับหนึ่ง
